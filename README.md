# 🚀 MemeVerse

A brutalist-themed, full-stack social meme platform featuring dynamic UI themes, interactive feed voting, local authentication, and an integrated **AI Studio Generation Engine**.

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **AI Engine:** Integrated Dynamic AI Image Studio
- **Auth:** JWT & Bcrypt

## ✨ Key Features

- 🤖 **AI Studio Prompt Engine:** Generate memes on the fly using custom prompt controls with cache-busting preview support.
- 🎨 **Dynamic Theme Engine:** Switch seamlessly between **Fresh 🌊**, **Trending 🔥**, and **Cursed ☣️** modes.
- 💬 **Interactive Feed:** Real-time upvoting (Ratio system) and nested comment threads.
- 🔒 **Local Auth:** Secure User registration & JWT authentication using local MongoDB setup.
